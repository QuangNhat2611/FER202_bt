# Exercise 14 - React Hook (useContext)

## Chạy project

```bash
npm install
npm run dev
```

Sau đó mở URL Vite hiển thị trong terminal, thường là `http://localhost:5173`.

## Chức năng

### Exercise 1
- `ThemeContext`
- `ThemeProvider`
- `useContext`
- Nút `Toggle Theme`

### Exercise 2
- `CartContext`
- Hiển thị danh sách món ăn
- `Add to Cart`
- `Remove`
- `Clear Cart`
- Hiển thị số lượng và tổng tiền

### Exercise 3
- `cartCount` và `cartValue` được tính lại ngay khi `cartItems` thay đổi.
- Không cần reload trang.

## Ảnh món ăn

- `zucchipakoda.png`
